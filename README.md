# AnonBroadcast

Author: Aziel Eliab

This download can print its status. It is not ready to render a communique yet.

When it ships, the next step will be the local renderer named in the repository description: text in, TTS voice, desk reel, metadata-culled MP4, and a SHA-256 receipt. That renderer is not in this package.

## See the status

1. `python3 -m pip install -e .`
2. `anon-broadcast`
3. `anon-broadcast --help`

`anon-broadcast --json` prints the same status for scripts.
